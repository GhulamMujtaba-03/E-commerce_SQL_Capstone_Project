# 🛒 E-Commerce SQL Capstone Project

## E-Commerce Business Performance & Sales Analysis

An **E-Commerce SQL Capstone Project** developed as part of my **internship**, focused on analyzing business performance and sales data using **MySQL**.

The project uses relational data from customers, orders, order items, and products to generate meaningful business insights through SQL queries, KPI calculations, aggregations, joins, ranking, time-based analysis, and profitability analysis.

---

## 📌 Project Overview

The objective of this project is to analyze e-commerce business data and answer important business questions such as:

* How much revenue is generated?
* Which countries and cities generate the highest sales?
* Which products and categories perform best?
* Which sales channels generate the most revenue?
* What are the most profitable countries, cities, and products?
* How does sales performance change over time?
* What are the Year-to-Date and Month-to-Date sales?
* How does the current year's performance compare with previous years?

The analysis covers sales data across **2023, 2024, and 2025**.

## 🗄️ Database Structure

The project works with four main relational tables:

```text id="m3x8q7"
Customers
    │
    │ customer_id
    ▼
Orders
    │
    │ order_id
    ▼
Order_Items
    │
    │ product_id
    ▼
Products
```

### Tables Used

| Table         | Description                                              |
| ------------- | -------------------------------------------------------- |
| `customers`   | Customer information such as country and city            |
| `orders`      | Order information including order date and sales channel |
| `order_items` | Product quantity and unit price for each order           |
| `products`    | Product name, category and cost price                    |

# 🔍 SQL Analysis

## 1. 🌍 Country Sales Analysis

The project identifies the **Top 5 countries by sales** for:

* 2023
* 2024
* 2025

## The analysis uses joins between `orders`, `order_items`, and `customers` and ranks countries according to total sales.

## 2. 🏙️ City Sales Analysis

The project identifies the **Top 5 cities by sales** for:

* 2023
* 2024
* 2025

This provides a geographic view of where the business generates the most revenue.

---

## 3. 📈 Time-Based Sales Analysis

The project performs time-based analysis using:

* Year
* Month
* YTD
* MTD
* Previous Year

YTD sales are calculated by grouping sales by year, while MTD sales are analyzed by month and year.

Previous-year performance is analyzed using the SQL `LAG()` window function.

---

## 4. 📱 Sales Channel Analysis

Sales performance is analyzed across different channels:

* **Web**
* **Mobile App**
* **Marketplace**

Channel-level sales are calculated separately for **2023, 2024 and 2025**.

---

## 5. 🛍️ Product Analysis

The project identifies the **Top 5 Products by Total Sales**.

Product performance is calculated by joining the `products` table with `order_items` and aggregating total sales.

---

## 6. 🗂️ Category Analysis

The project identifies the **Top 5 Product Categories by Total Sales**.

This helps determine which product categories contribute the most to overall revenue.
